# originals/

Put full-resolution photos here. One folder per album:

```
originals/
  chamonix/
    first-light-aiguille.jpg
  la-grave/
    spine-wall.jpg
```

Then run `npm run build`.

The contents of this folder are **not committed to git** — only the compressed
web copies the build writes into `public/photos/`. Keep your masters backed up
somewhere else; this repository is not a backup.

Accepted: `.jpg` `.jpeg` `.png` `.tif` `.tiff` `.webp` `.avif` `.heic` `.heif`
